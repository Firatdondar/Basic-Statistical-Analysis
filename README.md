# Basic Statistical Analysis of Student Scores

A straightforward Python script utilizing `pandas`, `numpy`, and `matplotlib` to perform descriptive statistical analysis on a dataset of student academic performances.

## Overview
This tool parses a text-based dataset containing Math and Turkish exam scores, calculates fundamental statistical metrics, and generates visual histograms to analyze score distributions.

## Features
* **Descriptive Statistics:** Automatically calculates Mean, Median, Mode, Standard Deviation, and Quartiles (Q1, Q2, Q3) for numerical datasets.
* **Data Visualization:** Generates and exports frequency distribution histograms (`score_distribution.png`) for quick visual analysis.

## Usage
1. Ensure your dataset (`veri_seti.txt`) is in the root directory.
2. Run the analysis:
   ```bash
   python main.py
