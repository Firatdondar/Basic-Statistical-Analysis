# Basic Statistical Analysis of Student Scores

A Python script utilizing `pandas`, `numpy`, and `matplotlib` to perform descriptive statistical analysis on a dataset of student academic performances.

## Overview
This tool parses a text-based dataset (`data set.txt`) containing Math and Turkish exam scores, calculates fundamental statistical metrics, and generates visual histograms to analyze score distributions.

## Features
* **Descriptive Statistics:** Automatically calculates Mean, Median, Mode, Standard Deviation, and Quartiles (Q1, Q2, Q3) for numerical datasets.
* **Data Visualization:** Generates and exports frequency distribution histograms (`score_distribution.png`) for quick visual analysis.

## Installation & Usage
1. Install the required Python libraries:
   ```bash
   pip install -r requirements.txt
   ```
2. Ensure your dataset (`data set.txt`) is in the root directory.
3. Run the analysis:
   ```bash
   python main.py
   ```
